# **Технологии Програмирования домашнее задание №2**
## *Система управления рецептами*
### **Запуск**
Создайте файл main 
Импортируйте в него Ingredient, Recipe, ShoppingList, DietaryRecipe  
Используйте в своих целях
### **Функции**
#### *Ингредиенты*
-Создание ингредиента(название, количество, единица измерения)  
-Сравнение ингредиентов  
-Удобное текстовое отображение ингредиентов  
#### *Рецепты*
-Создание рецепта из ингредиетнов  
-Добавление новых ингредиентов в рецепт  
-Масштабирование рецепта под количество порций  
-Удобный просмотр состава  
#### *Список покупок*
-Создание списка покупок из нескольких рецептов  
-Обьединение одинаковых ингредиентов для разных рецептов  
-Получение готового списка покупок  
-Удаление рецепта из списка покупок
